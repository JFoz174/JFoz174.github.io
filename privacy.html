Jemily Backups — Privacy Policy

Last updated: 9 September 2026

Purpose

Jemily Backups is a private application operated by James to back up personal household data using Restic and rclone. It is not a service offered to the public.

Google account access

The application requests Google Drive access using the drive.file permission. It creates, lists, reads, updates and deletes application-authorised files and their metadata to perform backups, integrity checks, retention and restoration. It does not request access to Gmail, contacts or calendars.

Storage and security

Restic encrypts backup contents and filenames before uploading them to Google Drive. Google stores the encrypted repository and associated storage metadata. Authentication credentials are stored on the operator's private server with restricted filesystem permissions. Recovery credentials are kept separately.

Use and sharing

Data is used only to operate and restore personal backups. It is not sold, used for advertising, or shared with other application users. Google Drive provides the cloud storage.

Retention and deletion

Recovery points are retained according to the configured backup policy: three daily, four weekly and three monthly. These categories can overlap. Obsolete backup data is removed during repository maintenance.

The account owner can revoke the application's access through their Google Account settings. Revoking access does not automatically delete existing backups; the owner can delete the repository separately from Google Drive.

This website

These information pages are hosted by GitHub Pages. No application analytics or advertising trackers are added. GitHub may process visitor information under its own privacy policy.
